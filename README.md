# QUAD//LAB · 사족보행 로봇 설계 실험실

**무료 GitHub Pages 정적 웹사이트 / 실험용 시제품 0.2.1**

## 사용 방법

1. 이 폴더의 모든 파일(`index.html`, `styles.css`, `app.js`, `scene.js`, `engineering.js`, `model.js`, `wiring-ui.js`, `codegen.js`)을 GitHub **공개 저장소의 루트**에 업로드합니다.
2. 저장소 `Settings > Pages > Build and deployment > Deploy from a branch`에서 `main`과 `/(root)`를 선택합니다.
3. 배포된 HTTPS 사이트를 엽니다. 설치나 서버 결제가 필요하지 않습니다.
4. 로컬 테스트는 폴더에서 `python -m http.server 8000` 명령을 실행한 뒤 `http://localhost:8000`을 열면 됩니다. `file://` 직접 열기는 모듈 보안 정책 때문에 작동하지 않을 수 있습니다.
5. 첫 접속에는 **Three.js CDN 네트워크 연결**이 필요합니다. 물리/기구 계산과 STL 파일은 이후 브라우저에서 처리합니다.

## 구현된 범위

- Three.js 3D 로봇(몸통·4개 다리·12개 관절)과 카메라 조작
- 각 다리 3자유도에 대응하는 **이론 각도** 계산: 벌림/회전 1축 + 2링크 평면 역기구학
- 크롤 보행 궤적, 발 들기와 접지 비율 조절
- 지지다각형의 정적 안정 여유, 지지 다리 간 **균등 분담 가정** 토크 계산
- 배터리 내부 저항·배선 왕복 저항·커넥터 저항, 4개 BEC의 독립 공급 경로 전류 및 전압 강하 계산
- 실제 배선도 SVG 편집: 포트 두 개를 클릭해 연결 추가, 선 클릭해 삭제, 단락·누락·BEC 출력 임의 병렬 검사
- 시판 부품 데이터베이스(Arduino Mega Rev3, PCA9685 계열 보드, 사용자 제공 DROYUKE 모터 사양), 사용자 부품 등록, 3D 상자 크기 근사 배치
- STL 기하 업로드(mm 가정), 프로젝트 JSON 저장/불러오기
- Arduino Mega + Adafruit PCA9685 라이브러리 기반 12채널 **실험용** 크롤 보행 `.ino` 생성(시리얼 `R 10`, `S`)

## 0.2 UI 조작 및 독립 구동 모드

- 설계 편집 중에는 **로봇이 자동으로 걷지 않습니다.** 하단 **별도 실행 화면에서 구동**을 눌러야 새로운 전체 화면에서 크롤 보행 애니메이션이 시작됩니다. 실행 화면의 **일시정지 / 다시 실행 / 구동 종료**는 서로 독립적으로 동작합니다. 종료 시 시간과 자세를 초기화하고 설계 화면으로 돌아옵니다. **이는 실제 Arduino 연결/모터 명령이 아닙니다.**
- **실제 부품** 탭 또는 3D 뷰 우측 하단의 **영역 선택** 버튼을 켜고 마우스로 드래그하면 화면에 놓인 Arduino/모터/BEC/배터리 *배치 부품*을 여러 개 선택합니다. `Shift+드래그`는 선택 추가이며, 버튼을 끄면 좌클릭 드래그는 카메라 회전으로 복귀합니다.
- 다중 선택 후 3D 이동축을 드래그하거나 **이동 ΔX/ΔY/ΔZ/회전 ΔY**를 입력하고 **선택 항목 한꺼번에 이동**을 눌러 변경합니다. `Delete` 키로 선택 부품 삭제, `Esc`로 선택 해제, `Ctrl+A`로 모든 배치 부품 선택이 가능합니다(입력 창에 포커스가 없는 경우).
- **선택 부품 색상**을 골라 일괄 적용할 수 있습니다. 로봇의 몸통/다리 링크/관절/서보 외형과 업로드한 STL 색상도 왼쪽에서 바꿀 수 있습니다. 색상과 부품 좌표는 프로젝트 JSON에 저장됩니다.
- 영역 선택 대상은 현재 **배치 부품 박스**이며, IK로 생성된 다리의 개별 메시를 영역으로 선택하여 편집하는 기능은 미구현입니다. 다리 형상/색은 별도 제어합니다.
- 현재 **실행 화면은 준정적 기구학 모션 미리보기**입니다. Rapier 물리 엔진, 실제 서보 제어 루프, SPICE 수준 회로해석 및 실시간 Arduino 제어 기능은 여전히 미구현입니다. 실제 동역학과 구분해 사용하세요.

## 실물 검증 전 주의

### 시뮬레이션 정확도의 한계

이 시제품은 **전체 강체 동역학이나 SPICE 전기 회로 시뮬레이터가 아닙니다.**

- 3D 애니메이션은 기구학에 기반합니다. 동적 충돌 반응, 질량분포 관성모멘트, 서보 기어백래시·PID, 마찰 접촉 솔버, 온도 의존 배터리 방전곡선은 구현되지 않았습니다.
- 질량·접촉력 계산은 간이 정적 평균화입니다. 중량이 4개 다리에 실제로 균등 분배된다고 단정할 수 없습니다.
- 서보 소비전류는 **토크에 비례한다고 가정한 간이 모델**입니다. 기본 스톨 전류 3.5A와 토크 30kgf·cm, BEC 지속전류 10A, 효율 88%, 외형·질량은 **검증된 실제 제품값이 아니라 예제값**입니다.
- 전류 제한을 넘을 때 BEC 전압이 비례해 감소하는 계산은 예시용 가정이지 실제 컨버터 보호 동작이 아닙니다.
- UI의 Arduino Mega는 USB 전원(벤치 실험)으로 구동된다고 가정합니다. **이동형 본체 탑재 전원 설계는 미완성**입니다. 실제 완전한 배터리 자율 운용 전에는 컨트롤러용 규격에 맞는 안정적 전원을 별도로 설계해야 합니다.
- 서보 드라이버 보드의 V+는 비어 있으며 **서보 모터 전원은 4개의 분리된 외부 BEC 분배 배선**에서 공급합니다. 모든 서보 신호의 기준 GND는 공통입니다. 실제 PCA9685 보드의 공통 V+에 네 BEC 출력을 무심코 연결하면 안 됩니다.
- 3D CAD/STL을 업로드해도 자동으로 질량/재료/핀/관절을 인식하지 않습니다. 상자 외형의 간섭 경고도 단순 축 정렬 경계상자 검사입니다.
- `.ino`는 **실물에서 모터의 기계적 중심, 회전 방향, PWM 펄스, 270° 회전 허용 범위 검증 후**에만 사용합니다. 각도 출력은 제한되므로 애니메이션을 그대로 따라가지 못할 수 있습니다. 특히 `outputServo()`의 PWM 매핑은 범용 가정이고 모터별 실측 보정이 필수입니다.

## 무료 운영 관련

코드는 서버/API 요청이나 유료 기능이 없습니다. 정적 GitHub Pages 서비스와 무료 Three.js CDN으로 구성됩니다. 사이트 호스팅에 사용량 기반 유료 기능을 활성화하지 않는 구조입니다. GitHub의 제공 조건, 공개 저장소 요구사항 및 사용량 소프트 한도는 별도로 적용됩니다.

## 시판 제품의 사양을 실제 계산에 적용하는 방법

1. `실제 부품`에서 등록된 서보를 고르고 `서보 사양 적용`을 누르면, 해당 부품의 기준 전압·스톨 토크·스톨 전류·대기 전류가 전원·토크 계산에 반영됩니다.
2. 등록된 BEC/전원 장치를 고르고 대상 `BEC 1~4`를 선택한 뒤 `전원 사양 적용`을 누르면 정격 출력·연속 전류·효율이 반영됩니다.
3. 미등록 제품은 '사용자 부품 직접 등록'에 값을 입력하거나 `example-part-spec.json`을 참고한 별도 JSON을 업로드하여 등록합니다.
4. 실제 제조사 페이지 URL을 저장할 수 있지만 자동으로 페이지를 긁어 사양을 추론하지는 않습니다. 공개 웹 페이지 자동 수집에는 CORS/API·이용약관 제약이 있습니다.
5. STL은 '기구·보행' 탭에서 업로드하여 3D 형상으로 볼 수 있으나, 이 시제품에서는 부품별 모델의 자동 결합/관절 추출을 지원하지 않습니다. **프로젝트 JSON에는 업로드한 STL 바이너리가 저장되지 않으므로** 다시 열 때 STL 파일을 별도로 업로드해야 합니다.

'실제 부품'이란 시판 모델명을 선택하거나 사용자가 실물 규격을 입력하는 기능을 뜻하며, *공식 자료 없이도 실제 특성을 모두 안다고 가정하지 않습니다.*

## 0.2.1 성능 최적화

정지 화면의 지속 프레임 루프를 제거하고, 보행 중 전원·진단 갱신을 약 220ms 주기로 분리하였다. 배선·간섭 결과를 재사용하고 geometry/material 정리 및 프로젝트 검증을 보완하였다. 자세한 기능·구조·한계·측정값은 [CODE_REVIEW_KO.md](./CODE_REVIEW_KO.md)를 참조한다. Node.js 20 이상에서 `npm test`로 회귀 테스트를 실행할 수 있다. 배포에는 npm이나 빌드 작업이 필요 없다.
